NOW: VM PROTOTYPE

Six gates.
One tangible goal.

  1. Stabilize the shell, navigation and touch experience.
  2. Select Linux-compatible reference hardware.
  3. Boot a usable native session on that device.
  4. Validate tablet features, then the phone-specific requirements.
  5. Prove enrollment, updates, data protection and recovery.
  6. Run a daily-use pilot with a repeatable image and guide.

Current milestone: the VM prototype. The roadmap’s concept phone and tablet illustrate the hardware target; the screenshots show the running development session.

Assemble the image.

Download both `.part` files and `DOWNLOAD-ISO.md` from the release. In their directory, run:

cat tessarchy-0.1.0-20261023-x86_64.iso.part??? > tessarchy-0.1.0-20261023-x86_64.iso
sha256sum -c SHA256SUMS

The checksum file verifies both parts and the complete ISO.
