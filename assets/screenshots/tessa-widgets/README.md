# Tessa touch widgets

This is an actual, unedited 1024×768 capture from the existing QEMU/KVM
development VM after the vanilla Hyprland baseline and first widget surface
were staged. It shows the preserved Tessarchy wallpaper with the calendar,
weather, media, and battery cards rendered through the active Tessa theme.

- [Tablet widget surface](tablet-widgets.png)
- [Capture manifest](manifest.json)

Physical touchscreen latency and hardware battery/media data remain untested in
the software-rendered guest.
