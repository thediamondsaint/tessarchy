# T cube v2 screenshots

Unedited captures from the Tessarchy development VM via QEMU `screendump`.

- `tablet-cube-collapsed.png` — compact, illuminated T cube affordance.
- `tablet-cube-expanded.png` — adaptive glass island with icon-only touch actions and an empty recents state.

The cube implementation adapts the Material 3 expandable FAB interaction pattern from end-4's GPL-3.0 Quickshell widgets; no source file was copied.
