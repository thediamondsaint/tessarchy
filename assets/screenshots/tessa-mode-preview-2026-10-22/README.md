# Tessa desktop and phone mode previews

These are source renders produced with Qt `qmlscene` in an offscreen software session using the current Tessa theme tokens, wallpaper, glass surfaces, bubble icons, and edge wheel. They are visual previews of the desktop and phone layouts, not VM captures.

The development VM disk is not present in this checkout (`vm/` is empty), so runtime screenshots cannot be truthfully produced until the existing VM disk is restored.
