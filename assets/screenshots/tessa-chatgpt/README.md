# Tessa ChatGPT integration

This directory contains an actual, unedited capture from the existing QEMU/KVM
development VM. It shows the tablet layout with the official `chatgpt-bin`
package installed and the Tessa ChatGPT panel open. The VM was intentionally
left signed out, so no account usage values are invented or displayed.

- [Tablet ChatGPT panel](tablet-chatgpt-installed-signed-out.png)
- [Capture manifest](manifest.json)

Physical sign-in, account usage, and native ChatGPT window rendering remain
unverified because no account credentials were entered in the development VM.
