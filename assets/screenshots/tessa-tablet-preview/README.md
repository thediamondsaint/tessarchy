# Tessa tablet preview

Actual 1024×768 VM captures using automatic Tablet layout, not design concepts.
Capture methods, source, dimensions and hashes: [manifest.json](manifest.json).

- [Live window scrolling with the bottom slider](scrolling.gif)
- [Bottom slider](bottom.png)

The native application windows remain full width as they move across the output.
The thumb gesture scales to the larger viewport; release snaps to the next app.
