# Tessa top bar and T cube screenshots

These are unedited screenshots captured from the running Tessarchy development VM via QEMU's `screendump` command.

- `tablet-topbar-touch.png` — touch-oriented floating glass top bar over the Tessa tablet home surface.
- `tablet-topbar-tcube-expanded.png` — the same top bar with the T cube expanded; launcher, navigation, settings, and phone/messages/keyboard/desktop shortcuts are icon-only touch targets inside the cube.
