# Omarchy palettes

The 23 palette directories other than `tessera` and `tessera-light` contain
unmodified `colors.toml` files copied from https://github.com/omacom/omarchy
at revision `82662dd2627db3b22c63616d3cae025aeb0f1e47`, inspected 2026-10-21.

Copyright (c) David Heinemeier Hansson. Distributed under the MIT license in
[OMARCHY-LICENSE](OMARCHY-LICENSE). Upstream theme names and palette values are
preserved. No upstream wallpaper, executable configuration or icon pack is
bundled. Tessa derives its existing shell surfaces and control glow from these
palettes; the native Tessa themes retain their optional semantic overrides.
